### 2.5 为什么没有现成的「构成主义 CSS 框架」

实测：以 `constructivist` 搜索 GitHub 全站，**总共只有 78 个仓库**，排在前面的全是机器学习/教育学（"constructivism" 在教育学里是"建构主义"）——**与视觉设计无关**。

**结论：这个风格的 CSS 框架生态是空白的。** GitHub 上**不存在**高星、在维护的"构成主义 CSS 框架"，也**不存在**独立的、维护中的"印刷套印错位（misregistration）CSS 库"（`css+overprint` 搜索仅 1 个 0 星无许可证仓库）。

这不是坏事——意味着你做出来的东西不会像某个模板。本项目的 `constructivism-kit/kv.css` 就是为填补这个空白写的。

## 4. 字体资源

### 4.1 结论速查（全部实测西里尔覆盖）

> 数据来源：`https://fonts.google.com/metadata/fonts`（1950 个字族逐族查询 `subsets` 字段），非凭印象。

✅ **支持西里尔**：**Oswald**、**Unbounded**、**Russo One**、**Rubik Mono One**、**Jost**、**Play**、**PT Sans / PT Serif / PT Mono**、**PT Sans Narrow**、**Roboto Condensed**、**Alumni Sans**、**Manrope**、**Onest**、**Golos Text**、**Commissioner**、**Noto Sans / Serif**、**Source Serif 4**、**IBM Plex Sans / Mono**、**JetBrains Mono**、**Fira Sans**、**Alegreya Sans**、**Comfortaa**、**Prata**、**Podkova**、**Oranienbaum**、**Yeseva One**、**Ruslan Display**、**Prosto One**、**Kelly Slab**、**Iceberg**、**Marmelad**、**Inter**、**Geist / Geist Mono**

❌ **不支持西里尔**（页面出现俄文即掉字体）：**Anton、Bebas Neue、Archivo、Archivo Black、Barlow、Barlow Condensed、Bricolage Grotesque、Anybody、Chivo、Space Grotesk、Syne、Teko、Saira Condensed、Fjalla One、League Gothic、League Spartan、Big Shoulders、Alfa Slab One、Ultra、Rye、Bevan、Rozha One、Chonburi、Michroma、Orbitron、Syncopate、Bodoni Moda**

> 🔴 **这是本次调研最有价值的单条信息。**
> - **Anton / Bebas Neue / Archivo Black / Barlow Condensed** 是设计师做"海报标题"时最顺手的四个选择 —— **全都没有西里尔支持**。
> - **`League Gothic` 是"窄体大写"的最佳选手之一，可惜不能上西里尔。**
> - **所有开源"工业木活字 / slab"字体（Alfa Slab One / Ultra / Rye / Bevan / Rozha One / Chonburi）全部无西里尔。** 该气质只能靠 Oswald / Russo One / Ruslan Display / PT Sans Narrow 近似。

**⚠️ 未找到**：`Molot`（常被推荐用于构成主义海报的西里尔展示体）在 Google Fonts 元数据中 **NOT-IN-GF**，也未定位到可信的开源仓库 → **不要使用来路不明的副本**。

## 7. ✅ 公有领域图像素材（**已实测验证**）

### 7.1 方法突破：Commons 网页被拦，但 **API 通**

本环境的 `web_fetch` 访问 `commons.wikimedia.org` 的**网页**会失败，但 **`commons.wikimedia.org/w/api.php` 完全可用**。这是一条通用经验：**被 Cloudflare 拦的是网页，不代表 API 也被拦。**

可复现的查询方式：
```powershell
# 按关键词搜文件，并直接带出许可元数据
$u = "https://commons.wikimedia.org/w/api.php?action=query&generator=search" +
     "&gsrsearch=El%20Lissitzky%20poster&gsrnamespace=6&gsrlimit=6" +
     "&prop=imageinfo&iiprop=url|extmetadata&format=json"
Invoke-RestMethod -Uri $u -Headers @{ 'User-Agent' = 'your-tool/1.0 (contact)' }
```
⚠️ **Commons API 限流较严**（实测连续请求会返回 **429**）。请放慢节奏（每次间隔 15–20 秒），并在 `User-Agent` 里写明用途与联系方式。

### 7.3 稳定链接模式（已验证）

不要硬编码 `upload.wikimedia.org` 的具体哈希路径（会变）。用 Commons 的官方重定向模式：

```
文件页：https://commons.wikimedia.org/wiki/File:<文件名>
直链  ：https://commons.wikimedia.org/wiki/Special:FilePath/<URL编码后的文件名>
```

**已实测**：`Special:FilePath/Beat%20the%20Whites%20with%20the%20Red%20Wedge.jpg` → **HTTP 200，301 KB**，正确重定向到 upload.wikimedia.org 原图。

### 7.4 🔴 版权判定：一个必须先看的陷阱表

**依据**：Wikimedia Commons 官方模板 [`Template:PD-Russia-1996/en`](https://commons.wikimedia.org/wiki/Template:PD-Russia-1996) 的逐字原文。
俄罗斯 PD 的判定条件是「**作者卒于 1942-01-01 之前**」；美国侧依据「URAA 日（1996-01-01）时在母国已 PD」。

| 艺术家 | 生卒年 | 俄罗斯 PD | 美国 PD | 结论 |
|---|---|---|---|---|
| **波波娃 Popova** | 1889–1924 | 已 PD | 已 PD | ✅ **零风险，可直接商用** |
| **马列维奇 Malevich** | 1879–1935 | 已 PD | 已 PD | ✅ **零风险** |
| **李西茨基 Lissitzky** | 1890–**1941-12-30** | 已 PD | 已 PD | ✅ **零风险**。只差 2 天就落在 1942-01-01 之后，但规则适用无疑义 |
| 罗德琴科 Rodchenko | 1891–1956 | **2027 年**才到期 | 仅 1930 年及以前出版的 | ⚠️ 只取 1930 年前出版物，并加免责说明 |
| 斯捷潘诺娃 Stepanova | 1894–1958 | **2029-01-01** | ⚠️ | ⚠️ 谨慎，建议回避 |
| **克卢西斯 Klutsis** | 1895–1938 | ⚠️ **表面已 PD，但有例外条款** | 已 PD | 🔴 **2027 年前建议回避**（见下） |

> 🔴 **克卢西斯陷阱（这是本次最容易被忽略的一条）**
> 他虽然 1938 年去世（表面符合「卒于 1942 前」），但 `PD-Russia-1996` 模板有脚注规定：
> **若作者曾遭镇压并获死后平反，保护期自平反年起算。**
> 若他的平反发生在 1956 年，则保护期顺延至 **2027-01-01**。
> （**他的确切平反年份我未能在可达页面核实** —— 标记为「未找到」，因此按最保守口径处理。）
> **→ 本项目的海报一律不使用克卢西斯作品。**

> 🟠 **Rodchenko 同样处于边缘状态**：俄罗斯侧 2027 年才到期；美国侧只认 1930 年及以前的出版物。
> 我在 `soviet-press` 页面里用的是**李西茨基**（零风险），没有用罗德琴科或克卢西斯的图像 —— 这是刻意的选择。

### 7.5 🔴 翻拍件陷阱（比版权到期更容易踩）

Commons 上大量标着"构成主义海报"的文件，**其实是 2021/2022 年现代摄影师的翻拍照片**，
授权是 **CC BY / CC BY-SA** —— **翻拍件本身是新的版权客体**，用它必须署名并以相同方式共享。

实测两例：
- `Varvara stepanova, giocatori di biliardo` → **CC BY-SA 4.0**，摄影 Francesco Bini，2022
- `Long Live the USSR! 1935` → **CC BY 2.0**，摄影 Steve Knight，2021

**筛选方法**：查 `extmetadata.Artist` **是不是画家本人**，再看 `DateTimeOriginal` 是不是 1920s。
两个条件都满足才是真·扫描件。

**真·PD 高清件（实测像素）**：

| 文件 | 尺寸 | 备注 |
|---|---|---|
| `Beat the Whites with the Red Wedge.jpg` | 1920 × 1572 | 李西茨基 ✅ 本项目在用 |
| `Malevich, Kazimir Severinovich - Black Square.jpg` | 8032 × 8000（52 MB） | 马列维奇 ✅ |
| `Under the banner of Lenin… Klucis` | 4000 × 5516（3.19 MB） | 克卢西斯 🔴 **2027 年前回避** |

### 7.6 ⚠️ 其他仍需注意

1. ⚠️ **`LicenseShortName = Public domain` 是 Commons 社区自己的判定**，不是法律意见。**商用前请逐件复核**。
2. ⚠️ **Art Institute of Chicago API 也可调用**（`https://api.artic.edu/api/v1/artworks/search`，返回 `is_public_domain`），但实测以 `constructivism` 检索出的俄国纺织品设计 **多为 `not-PD`**，价值有限。
3. ❌ **已实测失效的 API**：Met Museum（HTTP 410）、Rijksmuseum（410）、Europeana（401，需 key）。
