# 构成主义美学谱系与形式法则

> 目的：把「构成主义」从一堆风格印象，压缩成**可以照着做决策的形式规则**。
> 阅读顺序：先看第 0 节建立坐标系，再看第 3 节的九条形式法则（这是真正要用的部分），第 2 节的代表作当"字典"查。

## 0. 先分清三个容易混淆的词

做网页之前必须先分清这四件事，否则做出来的东西会变成"混搭拼贴"。

| 名称 | 时间 | 核心主张 | 视觉长什么样 | 对网页的用处 |
|---|---|---|---|---|
| **至上主义** Suprematism | 1915– | 马列维奇：纯感觉至上，形体脱离现实 | 纯几何（方块、圆、十字），**斜置**，白底上的黑/红/黄方块，无文字 | 提供**几何原语**与斜向动势 |
| **构成主义** Constructivism | 1915–1930s | 塔特林/罗德琴科：艺术是"建造"，艺术家=工程师，为革命服务 | 拼贴照片 + 巨大文字 + 红黑白 + 对角线 | **主视觉语言**：构图、排版、拼贴 |
| **生产主义** Productivism | 1921– | 构成主义的应用分支：放弃架上绘画，进工厂、进印刷所 | 书籍、海报、纺织品、广告 | 说明"设计必须有用"的正当性 |
| **粗野主义 Web** Brutalist Web | 2014– | Copeland：网站的材料不是 HTML 是**内容**，诚实、快、可用 | 裸排版、下划线链接、默认按钮 | 提供**可用性底线**，防止风格毁掉体验 |

**关键判断**：三者气质相近但不是一回事。
- 至上主义 = 纯几何、无文字、精神性 → 适合做**背景图形与装饰层**
- 构成主义 = 几何 + **照片** + **文字** 三者咬合 → 这才是网页主角
- 粗野主义 Web = 一套**可用性纪律** → 当作约束条件，不是视觉风格

> 常见错误：把构成主义做成"包豪斯"。包豪斯是理性的、网格化的、偏冷的；构成主义是**倾斜的、宣传性的、有冲突感**的。如果页面全部横平竖直、四平八稳，那就已经跑偏成瑞士国际主义了。

## 1. 一句话把握它的世界观

1915 年塔特林在巴黎看过毕加索的拼贴构造后，回国开始用铁、玻璃、木头做**不表现任何东西、只展示材料本身**的立体作品。1917 年十月革命后，这批艺术家把"建造"当作新社会的技术活儿。

他们自己的原话（可直接拿来做文案的基调）：

> "艺术不能集中在叫做博物馆的死寂神殿里。它必须散布到各处——街道、电车、工厂、车间和工人家中。"
> —— 弗拉基米尔·马雅可夫斯基

> "材料的成形要取代审美的组合。对象应被当作一个整体来处理，因而没有可辨认的'风格'，只是像汽车、飞机那样的工业秩序产物。构成主义是纯粹的技术性掌控与材料组织。"
> —— 1923 年《Lef》杂志宣言（Tate 引）

> "我们把自己当工程师，把作品当构造：我们像装配工一样装配我们的作品。"
> —— 劳尔·豪斯曼（论照片拼贴）

**对网页设计的直接推论**：
1. **反装饰**——每个元素都要"有用"，不能是纯粹的漂亮。
2. **暴露构造**——网格、分隔线、编号、印刷标记都可以"露出来"，不必藏。这是与瑞士风格最大的差别：瑞士风格隐藏网格，构成主义**炫耀网格**。
3. **材料自觉**——照片、字体、色块是三种"材料"，要让人看见它们是被拼接的，而不是无缝融合的。

## 3. 九条形式法则（**核心可用部分**）

这九条是判断"像不像构成主义"的可操作标准。每条给出：原则 → 视觉手段 → Web 实现。

### 法则 1：对角线是默认动势，不是例外
构成主义反对水平-垂直的静态平衡。画面要被一条 15°–45° 的斜轴穿过。

- **视觉手段**：主梁斜线、斜置的色块、倾斜的标题块、斜切的图片边缘
- **Web 实现**：`transform: rotate()` 承载文字/图片；`clip-path: polygon()` 做斜切；`repeating-linear-gradient` 画斜向网纹；用一条贯穿全页的 `position: absolute` 斜条作为"主梁"
- **反面**：整页只有直角方块 = 瑞士/包豪斯，不是构成主义

### 法则 2：红 / 黑 / 白 三色，且比例失衡
经典印刷是**红、黑**双色油墨印在**米白纸**上。不是"三色等分"，而是**以大量纸白为主，黑色压住结构，红色只用于引爆点**。

- 红色**只占 5%–15%** 的面积，但必须出现在最关键的 1–2 个地方
- **反例**：把整页染红、或红黑面积均等。那会变成"警告色"而不是构成主义
- 详见 [02-设计系统规格.md](./02-设计系统规格.md) 的色板与对比度实测数据

### 法则 3：几何原语只用四种
圆、矩形、三角楔、线。**不用曲线、不用渐变、不用柔和阴影、不用圆角。**

- 楔形（尖角三角）是**标志性符号**，优先级最高
- **Web 实现**：`border-radius: 0` 全局；`clip-path: polygon()`；SVG `<circle>/<rect>/<polygon>`
- 允许的例外：半调网点（它本质是"点阵"，仍是原语）

### 法则 4：字号对比必须极端
一个词占满整屏是正常操作。罗德琴科的"КНИГИ"就是几个字母吃掉整张海报。

- **标题 : 正文 ≥ 6 : 1**（瑞士风格通常 2.5–3 : 1，构成主义要更狠）
- 全大写（UPPERCASE）+ 极紧字距 + 极窄行高
- **Web 实现**：`font-size: clamp(3rem, 14vw, 14rem)`；`letter-spacing: -0.02em`；`line-height: 0.85`

### 法则 5：照片是"材料"，不是"配图"
照片在构成主义里承担客观性——它证明"这是真的"。但照片**必须被加工**：剪成几何形状、去背、半调化、双色调化、局部放大。

- **Web 实现**：`clip-path` 裁切 + `filter: grayscale() contrast()` + 双色调（见技术手册）+ `mix-blend-mode: multiply` 叠纸
- **禁止**：圆角卡片里放一张规规矩矩的 16:9 图 —— 那是 SaaS 落地页，不是构成主义

### 法则 6：文字与图像必须咬合，不能互相避让
文字可以**压在照片上**、可以**切断色块**、可以**溢出边界**。图文是拼接关系，不是排版关系。

- **Web 实现**：`mix-blend-mode` 让文字与底图相乘；绝对定位让文字压住图片；允许元素有意溢出容器
- **注意**：必须验算压字处的对比度（见设计系统文档）

### 法则 7：网格要露出来，并且允许被打破
构成主义大量使用网格和编号（这是"工程师"自我认同的体现），但网格是**可见的、有时被故意冲破的**。

- **视觉手段**：可见的细线栅格、坐标刻度、印刷裁切标记、编号、尺寸标注
- **Web 实现**：`repeating-linear-gradient` 画底纹网格；细 `border` 当分栏线；给区块加 `01 / 04` 形式的编号
- **与瑞士风格的关键差别**：瑞士网格是不可见的秩序；构成主义网格是可见的构造证据

### 法则 8：质感来自"廉价印刷"，不是"做旧滤镜"
真实的构成主义海报是**廉价胶版纸 + 有限的油墨**：纸偏米黄偏灰、墨有网点、套印会错位、边缘会脏。

- **视觉手段**：纸张米黄色（而非纯白）、半调网点、套印错位（红版与黑版偏移 1–3px）、轻微颗粒
- **Web 实现**：SVG `feTurbulence` 做颗粒；`text-shadow` 或伪元素 + `mix-blend-mode` 做套印错位
- **尺度警告**：这些质感必须**极轻**。超过一定程度就从"印刷感"变成"复古滤镜"，廉价而不锋利

### 法则 9：动效必须机械化，不能柔顺
工业时代的机器是**分段、突然、有阻尼**的，不是苹果式的丝滑缓动。

- **Web 实现**：`cubic-bezier(0.85, 0, 0.15, 1)` 或 `steps()`；时长 120–320ms；**禁止**回弹/弹性缓动；`prefers-reduced-motion` 下全部关闭
- **推荐动作**：色块**硬切**入、文字**逐行跳出**、图片**裁切框扫过**、数字**跳变**

## 4. 什么会露馅：五个典型误用

| 误用 | 为什么错 | 修正 |
|---|---|---|
| 圆角卡片 + 柔和投影 + 渐变 | 这是 2015 年后的 SaaS 语言，与"硬边、零装饰"完全相反 | `border-radius: 0`，投影改为纯黑硬阴影或直接不用 |
| 紫粉渐变 / 霓虹色 | 构成主义的颜色来自**油墨**，不是屏幕光 | 只用油墨色板，红色只做点缀 |
| Inter / Roboto 当标题 | 太中性、太当代，读起来是"模板" | 换 Oswald / Unbounded / Russo One，且必须确认西里尔覆盖 |
| 斜着排一整段正文 | 斜排正文的阅读性与可访问性极差 | **只有短标题、短标签、装饰性文字可以斜排**，正文永远水平 |
| 满屏红黑高对比 | ①对比度不足会伤可访问性 ②失去了红色的"引爆"价值 | 大量纸白打底，红只占小面积；红字只用于大字号 |

## 5. 与"中文语境"的适配注意

如果页面要放中文：

1. **中文没有天然的"窄体大写"传统**，直接套西文构成主义会别扭。解决：标题用**得意黑 Smiley Sans**（窄斜中文字，气质极其贴合，OFL-1.1），或思源黑体 Heavy + 强制 `letter-spacing` 收紧。
2. **中英混排**：西文用 Oswald/Unbounded，中文用得意黑/思源黑体，两者都要 `font-weight` 对齐视觉重量。
3. **中文标点**：开引号、破折号在紧字距下容易挤压，需要 `text-spacing-trim` 或手动 `letter-spacing` 微调。
4. **中文不适合作斜排**——笔画密度高，旋转后识别率下降明显。斜排只留给短西文标签。

## 6. 一句话总结（给设计决策用）

> **构成主义网页 = 米黄纸底 + 黑墨压结构 + 朱红引爆点 + 四种几何原语 + 一条斜轴 + 极端字号对比 + 可见的网格 + 被加工过的照片 + 机械化的动效。**

少任何一项都还能看，但会明显"不够劲"；**同时丢掉"斜轴"和"极端字号对比"这两项，就不是构成主义了。**
