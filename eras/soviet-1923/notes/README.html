最重要的实测结论#

这条是最容易被"看起来还行"骗过的：

# 结论 影响
1 Anton / Bebas Neue / Archivo Black / Barlow Condensed 全都没有西里尔字形 页面一出现俄文就掉字体。这是设计师最顺手的四个"海报字体"。League Gothic、所有开源 slab 木活字字体也一样
2 同一个颜色在不同底色上的可用性可以完全反转 #d4a843 金星 on 纸 = 1.82（废），on 黑 = 7.86（好）。必须逐对算，不能给颜色本身打标签
3 #cc0000 苏维埃红在泛黄纸上 = 4.84:1，反而过 AA 正文线 而更亮的 #D6281F 只有 4.15（仅大字）。直觉不可靠
4 #cc0000 on 纯黑只有 2.96:1 禁止在黑底上用红字
5 multiply 只会让结果变暗 浅色字用 multiply 等于把字抹掉 —— 本次真的这么干过，巨型标题直接消失
6 clip-path 会连 outline 一起裁掉 键盘焦点环消失，直接违反 WCAG 2.4.7。裁剪必须外移到装饰层
7 伪元素 content: attr(...) 的内容会被读屏软件朗读 "复制文字做效果"必须用带 aria-hidden 的真实节点，否则标题念两遍
8 GitHub 上不存在"构成主义 CSS 框架" constructivist 全站仅 78 个仓库，几乎全是教育学/机器学习。所以本项目自己写了 kv.css
9 克卢西斯（Klutsis）不是"可自由使用"的公有领域 他 1938 年去世表面符合俄罗斯 PD，但模板有例外条款：若作者遭镇压并获死后平反，保护期自平反年起算 → 可能到 2027。这条我早期搞错过，后来更正
10 能靠读代码发现的 bug 是少数 本次近 30 个问题，绝大多数靠截图逐张看或把数值算一遍才发现

已验证 vs 未验证#

已直接验证（有可复现的方式）： - 字体西里尔覆盖 —— Google Fonts 官方元数据 + 字体二进制 cmap 解析 - 色彩对比度 —— WCAG 相对亮度公式精算 - GitHub 仓库星数与许可证 —— api.github.com 实际返回 - CSS 兼容性 —— MDN Baseline 标识 + MDN BCD / caniuse 原始 JSON - 公有领域图像 —— Wikimedia Commons API 逐件查询 + 直链实测 200 - 参考站点技术令牌 —— 直接抓取其生产 CSS 提取字体/色板/clip-path - 交互链路 —— 无头浏览器 --dump-dom 功能测试 + 纯逻辑单元测试 - 页面实际长相 —— 无头截图逐张审

未能验证： - 各作品逐件的精确版权状态（Commons 的 PD 标记是社区判定，不是法律意见） - 俄文论文《构成主义对现代网页设计的影响》全文（PDF 无法读取） - @property / animation-timeline / text-spacing-trim 的兼容性 - 厂商中文字体（阿里普惠体 / MiSans / HarmonyOS Sans）的官方授权页 - StyleKit 构成主义规则的原文 —— 由用户提供并声明已抓取确认，本环境未二次核验，记为「用户实测来源」

详见 03-资源清单.md 的「交付缺口清单」。

怎么用 src/verify/ 里的脚本#

⚠️ Windows 默认禁止运行未签名的 .ps1。下面统一加 -ExecutionPolicy Bypass。 脚本本身都带 UTF-8 BOM（PowerShell 5.1 读无 BOM 的 UTF-8 会乱码 —— 见 09-踩坑清单.md F6）。

cd C:\...\结构主义html

# 原型页在另一个工作区 —— 用变量指过去，脚本本身与项目解耦
$proj = 'C:\...\视频工作流\soviet-press'

# 静态检查（每次改完都跑）
powershell -ExecutionPolicy Bypass -File .\verify\static-check.ps1 -Dir $proj

# 纯逻辑单元测试（不需要浏览器）
node .\verify\route-test.js

# 交互链路 —— 先跑快路径验状态机
powershell -ExecutionPolicy Bypass -File .\verify\flow-test.ps1 `
  -Page "$proj\index.html" -TestScript .\verify\example-flow-test.js

# 再跑一次真实动画路径
powershell -ExecutionPolicy Bypass -File .\verify\flow-test.ps1 `
  -Page "$proj\index.html" -TestScript .\verify\example-flow-test.js -NoStub

# 截图（记得逐张看）
powershell -ExecutionPolicy Bypass -File .\verify\shot.ps1 `
  -Page "$proj\index.html" -Out "$proj\_shots"

脚本都以 -Dir / -Page 参数化，换项目直接改路径即可。
