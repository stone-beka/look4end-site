1. 核心结论（先看这个）#

要开始一个构成主义网页项目，真正需要装的其实只有 6 样东西：

# 需要什么 用什么 为什么是它
1 一个现成的构成主义站点源码当起点 lsqkk/gallery（4★, MIT） ⭐ 全清单风格吻合度最高。Astro 构建，含 feTurbulence 噪点 multiply 叠层 + 印刷裁切线 + 西里尔水印。星数极低但风格与授权都最干净
2 一套 token 骨架 argyleink/open-props（5,539★, MIT） 把 --radius-* 全部覆写为 0、只用粗描边 + 固定间距阶梯，就得到构成主义 token 体系
3 一套字体 Oswald（标题）+ PT Sans（正文）+ JetBrains Mono（标签）+ 得意黑（中文标题） 全部实测支持西里尔；得意黑是中文里少见的窄斜海报字（OFL-1.1）
4 半调网点 + 纸颗粒 paper-design/shaders（3,589★, Apache-2.0） 含 dithering / dot-grid / grain-gradient / perlin-noise，正是印刷质感的全部所需
5 印刷级排版细节 davidmerfield/Typeset（2,680★, CC0） 悬挂标点、小型大写、视觉边距对齐——浏览器至今没实现，它用 <1KB CSS 补齐。CC0 = 无条件商用
6 基础层 + 生成式几何 csstools/sanitize.css（CC0）+ css-doodle/css-doodle（6,060★, MIT） sanitize 是 CC0 最佳基础层；css-doodle 用几十行生成整版至上主义几何构图

其余都是"锦上添花"或"仅作参考，不要抄代码"。

2.5 为什么没有现成的「构成主义 CSS 框架」#

实测：以 constructivist 搜索 GitHub 全站，总共只有 78 个仓库，排在前面的全是机器学习/教育学（"constructivism" 在教育学里是"建构主义"）——与视觉设计无关。

结论：这个风格的 CSS 框架生态是空白的。 GitHub 上不存在高星、在维护的"构成主义 CSS 框架"，也不存在独立的、维护中的"印刷套印错位（misregistration）CSS 库"（css+overprint 搜索仅 1 个 0 星无许可证仓库）。

这不是坏事——意味着你做出来的东西不会像某个模板。本项目的 constructivism-kit/kv.css 就是为填补这个空白写的。

4.4 字体获取与判定技巧#

# ① 权威判定西里尔覆盖（查 1950 个字族的官方元数据）
$m = Invoke-RestMethod 'https://fonts.google.com/metadata/fonts'
$m.familyMetadataList | Where-Object { $_.subsets -contains 'cyrillic' } | Select-Object family

# ② 另一条判定路径：带 text= 请求西里尔字符，字体不含该字形会报错
Invoke-WebRequest 'https://fonts.googleapis.com/css2?family=Oswald&text=%D0%9F%D1%80%D0%B8%D0%B2%D0%B5%D1%82'

4.5 ⚠️ 字体授权的两个"看起来能用、其实有坑"#

① Fontshare（ITF FFL）—— 建议整个排除

项 实测结论
授权 ITF FFL Version 2.0（2026-08-17）。可商用、可自托管（CSS @font-face）、署名非强制
🔴 但明文禁止 subset（子集化）、格式转换、放进任何 repository 分发
后果 常规的 next/font / Fontsource / glyphhanger 工作流会直接违规
西里尔 ❌ 全部 100 款字体的 languages 字段没有一款含 Russian / Ukrainian / Cyrillic
涉及字体 Clash Display、Cabinet Grotesk、Satoshi 等

→ 本项目排除 Fontshare。授权文本取自它自己的 402KB bundle（fontshare.com/js/main.<hash>.js，因为授权页是纯 JS 单页）。

7.1 方法突破：Commons 网页被拦，但 API 通#

本环境的 web_fetch 访问 commons.wikimedia.org 的网页会失败，但 commons.wikimedia.org/w/api.php 完全可用。这是一条通用经验：被 Cloudflare 拦的是网页，不代表 API 也被拦。

可复现的查询方式：

# 按关键词搜文件，并直接带出许可元数据
$u = "https://commons.wikimedia.org/w/api.php?action=query&generator=search" +
     "&gsrsearch=El%20Lissitzky%20poster&gsrnamespace=6&gsrlimit=6" +
     "&prop=imageinfo&iiprop=url|extmetadata&format=json"
Invoke-RestMethod -Uri $u -Headers @{ 'User-Agent' = 'your-tool/1.0 (contact)' }

⚠️ Commons API 限流较严（实测连续请求会返回 429）。请放慢节奏（每次间隔 15–20 秒），并在 User-Agent 里写明用途与联系方式。

🟠 Rodchenko 同样处于边缘状态：俄罗斯侧 2027 年才到期；美国侧只认 1930 年及以前的出版物。 我在 soviet-press 页面里用的是李西茨基（零风险），没有用罗德琴科或克卢西斯的图像 —— 这是刻意的选择。

7.5 🔴 翻拍件陷阱（比版权到期更容易踩）#

Commons 上大量标着"构成主义海报"的文件，其实是 2021/2022 年现代摄影师的翻拍照片， 授权是 CC BY / CC BY-SA —— 翻拍件本身是新的版权客体，用它必须署名并以相同方式共享。

实测两例： - Varvara stepanova, giocatori di biliardo → CC BY-SA 4.0，摄影 Francesco Bini，2022 - Long Live the USSR! 1935 → CC BY 2.0，摄影 Steve Knight，2021

筛选方法：查 extmetadata.Artist 是不是画家本人，再看 DateTimeOriginal 是不是 1920s。 两个条件都满足才是真·扫描件。
