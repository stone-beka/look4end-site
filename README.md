# Look4End

`look4end.com` 的网站源码。纯静态 HTML + CSS —— 没有框架、没有构建步骤、没有外部依赖
（不引字体、不引 CDN），断网打开也是完整的。

站上现在是一组关于**「设计 HTML」这件事本身**的文档：一个具体风格（构成主义）的美学考据，
加上实现过程中沉淀下来的、可跨项目复用的规则与踩坑。
所有关键数值都经过实测或精算，未验证的部分明确标注。

## 改内容

**这一批 HTML 是构建产物，不是手写源。** 正文以 Markdown 为源，由本机的构建脚本生成；
源文件和脚本不在这个仓库里。直接手改 HTML，下一次构建就会把它盖掉 ——
要改正文，去改源，重新构建，再把产物覆盖过来。

只有这几样是直接手改的：

| 想改什么 | 改哪儿 |
|---|---|
| 配色、字体、间距、网格 | `notes/kit/kv.css`（`:root` 里的变量） |
| 文档页版式（正文栏、目录、表格） | `notes/doc.css` |
| 首页 | `index.html` + `press.css` / `press.js` |
| 错误页 | `404.html` |

## 发布

**双击 `publish.bat`。** 它把改动收集起来、记一笔提交、推到 GitHub；
Cloudflare Pages 随即自动重建，**约 30 秒后刷新 look4end.com 就是新的。**

上一次没推成功的，双击它也能补上 —— 哪怕没有新改动，它也会检查有没有
「已经提交、卡在本机没上去」的提交，有就补推一次。

想手动做也行：

```bash
git add -A
git commit -m "说明你改了什么"
git push
```

## 两条硬规矩

1. **页面里不许引外部资源** —— 字体、CDN、第三方统计都不要。读者断网打开必须依然完整，
   这是站点的立身之本，不是技术洁癖。
2. **`.bat` 里不许写中文注释。** cmd.exe 会在某些字节位置从汉字中间切开一行，
   报出 `'击了跟没点一样...' is not recognized` 这种极难复现的错（2026-09-17 踩过）。
   `publish.bat` 里的中文只出现在 `echo` 输出的行里。
