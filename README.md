# Look4End

`look4end.com` 的网站源码。纯静态 HTML + CSS —— 没有框架、没有构建步骤、没有外部依赖（不引字体、不引 CDN），断网打开也是完整的。

> 「不引外部资源」讲的是**读者侧** —— 断网也要能读完，这是网站的性格，不是技术洁癖。
> 它只约束这个文件夹。写作台是本机工具，不受这条限制。

## 项目结构

```
look4end-site/
├── index.html            首页
├── style.css             全站共用样式（所有页面的外观都在这一个文件里）
├── 404.html              访问不存在的地址时显示的页面
├── og-image.png          分享到微信 / QQ 时显示的预览图（1200×630）
├── robots.txt            告诉搜索引擎可以抓什么
├── sitemap.xml           给搜索引擎的页面清单
├── posts/index.html      栏目：思想笔记
├── games/index.html      栏目：或许未来里面会放idea
├── timeseed/index.html   栏目：TimeSeed
├── goodnight/index.html  栏目：晚上好
├── assets/               文章里用的图（用到了才会有这个文件夹）
├── publish.bat           双击就能发布的脚本
└── README.md             本文件
```

栏目不是写死的：首页 `<nav class="nav">` 里那几行、`sitemap.xml`、
以及每个栏目文件夹，**都跟着本机写作台里的「知识库」清单走**。
要加一个栏目、改栏目名、删栏目，在写作台的入口页点，别手改这几个文件。

## 一、改内容

### 改首页文案

首页上的**标题、副标题、简介、正文那几段**，在**本机的写作台**入口页上直接改、直接发布。
不用打开 `index.html`，也不用手改草稿箱里的 `首页文字.txt` —— 那个 txt 只是写作台
发布时顺手抄的**副本**，给你翻着看用的。**首页上的字以线上那页为准**，
副本落后了不作数（写作台里点一次「发布首页」就把它抄齐）。

> **简介**（搜索结果和微信 / QQ 卡片上显示的那句话）在 `<head>` 里写了三遍
> （`description`、`og:description`、`twitter:description`），**要改就一起改**。
> 只改一处会出现"搜索里是新的、分享卡片还是旧的"—— 页面上看不出来，把链接贴出去才现形。
> 写作台会自动三处一起换，手改的话记得三行都改。

想往首页加别的东西（不是这几样字，而是新元素），才需要打开 `index.html` 手改：
文字全是明文，存盘就生效。**但导航那一行别手改**，见下面「加 / 改栏目」。

### 改颜色

打开 `style.css`，最上面 `:root` 里的六个变量管着全站外观：

| 变量 | 管什么 |
|---|---|
| `--bg` | 页面背景 |
| `--fg` | 标题、主文字 |
| `--fg-dim` | 正文、副标题 |
| `--fg-faint` | 方括号、返回链接 |
| `--accent` | 强调色（只在鼠标悬停时出现） |
| `--line` | 那两条发丝分隔线 |

**改一处，全部页面一起变。**

## 二、加东西

### 发一篇文章

**不用手写。** 文章页和列表页由本机的**写作台**生成 —— 写、改、发布、撤回都在它里面点。

> **为什么文章用数字命名？** 网址最短最干净（`look4end.com/posts/001.html`），编号还能保证排序。中文文件名在网址里会变成 `%E6%88%91...` 一长串，所以不用。
> **这个结构别改。** 改成日期目录或语义化网址，已经分享出去的链接会全部失效。

**各个栏目文件夹里的 html 请不要手动编辑** —— 文章页和列表页都由写作台按自己的规矩生成，
手改会被下一次发布覆盖掉。

### 加 / 改 / 删一个栏目

**不要手改首页的 `<nav class="nav">`，也不要手建文件夹。**
在本机写作台的入口页上点「＋ 新建知识库」（改名、删除也在同一处）。
写作台会一次做齐这几件事：

- 建 / 改名 / 删掉那个栏目文件夹和它的 `index.html`
- 首页 `<nav class="nav">` 里增删改对应的那一行
- `sitemap.xml` 跟着改

所以**栏目表的源头不在这份代码里**，是写作台里的「知识库」清单。

> 手改会打架：写作台下次一动栏目，就把手改的那行盖回去，或者把它算成"别人有没提交的改动"
> 而拦住发布。

（那条 nav 链接长这样，看一眼心里有数就行，别照着写：
`<a href="posts/"><span class="br" aria-hidden="true">[</span>思想笔记<span class="br" aria-hidden="true">]</span></a>`
—— `<span class="br">` 就是左右方括号，`aria-hidden` 是让读屏软件别把方括号念出来。）

### 文章里放图

图由写作台收：工具栏的「图片」按钮、直接**粘**进去、或者把文件**拖**进去，三条路都行。

图片会存进 `assets/`，文件名是它自己内容的指纹（一串 16 位的十六进制），所以：

- 同一张图传两次，落地的还是同一个文件，不会堆重复
- 图片一旦进去就**不会被改写或删除**（撤回文章也不删），已经发出去的链接永远有效
- 单张上限 2MB，只收 PNG / JPG / GIF / WebP

> ⚠️ `assets/` 里没有访问控制 —— 谁能猜到或拿到那个网址，谁就能看到那张图。
> 放上去的图就当是公开的。

### 改分享卡片的预览图

把链接发到微信 / QQ 时对方看到的那张卡片，由每个页面 `<head>` 里的 `og:` 标签决定。

- **换预览图**：替换 `og-image.png`（保持 1200×630 最保险）
- **换卡片文字**：改对应页面里的 `og:title` 和 `og:description`

> ⚠️ `og:image` **必须写完整网址**（`https://look4end.com/og-image.png`），写相对路径微信认不出来。

**文章页的 og 标签不用管** —— 写作台生成每一页时会连标题、日期、网址一起写好。
只有**手加的页面**（比如上面那种"想往首页加别的东西"）才需要自己配一套：直接复制
`posts/index.html` 里那段改，但记得把 `og:url` 和标题换成这一页自己的 ——
忘了换的话，分享出去会显示成别的页面的标题。

## 三、发布

**双击 `publish.bat`。** 它会自动做三件事：把改动收集起来、记一笔存档、传到 GitHub。

**上一次没传成功的，双击它也能补上**：哪怕你什么都没新改，它也会看一眼有没有
「已经存好、卡在本机没上去」的提交，有就替你补推一次。

传完后 Cloudflare 会自动重新部署，**大约 30 秒后刷新 look4end.com 就是新的。**

写作台里发文章也是走这条路（发布时会顺手推一次）。**推失败的时候它不会装作成功**：
文章会挂一个黄色的「待推送」，入口页上冒出一个「重试推送」按钮，点它重推就行 ——
稿子已经在本机了，不会丢。

想手动做也行，三条命令：

```bash
git add -A
git commit -m "说明你改了什么"
git push
```
