色彩系统

面积配比是硬约束

03

几何原语

只用四种

圆、矩形、三角楔、线。不用曲线、不用渐变、不用柔和阴影、不用圆角。 楔形（尖角三角）是识别度最高的符号 —— 它来自李西茨基 1919 年的《用红色楔子打击白军》。

WEDGE 楔形

clip-path: polygon()，必须锁 aspect-ratio 防止尖角变形。

CIRCLE + BAR 圆与斜梁

红楔刺入圆 —— 直接用 mix-blend-mode: multiply 叠印。

RULE 线

粗线 6px 是构成主义特征，与瑞士风格的 1px 细线形成对比。

VISIBLE GRID 可见网格

瑞士风格隐藏网格；构成主义炫耀网格 —— 这是最大的差别。

04

印刷质感

必须极轻

目标是「这是印出来的」，不是「这是做旧滤镜」。 判断阈值：把页面缩到 50% 看 —— 如果颗粒依然明显，就是太重了。

06

动效

机械化，禁止回弹

工业时代的机器是分段、突然、有阻尼的，不是苹果式的丝滑缓动。 统一使用 cubic-bezier(0.85, 0, 0.15, 1)，时长 120–320ms， 禁止弹性缓动与超过 400ms 的动画。把鼠标移到方块上试试。

硬切位移

transform + 机械缓动，无淡入。

裁切框扫过

用 clip-path: inset() 揭示，像印刷机的过版。

色块硬切

120ms 内完成颜色切换，几乎无过渡感。

降级：本页所有动效都遵守 prefers-reduced-motion。 开启该偏好后，动画时长被压到 0.01ms、滚动字幕停止。 实测：本系统全部关键 CSS 特性（clip-path / mix-blend-mode / background-blend-mode / text-wrap / shape-outside / mask / writing-mode / font-variant-numeric / SVG feTurbulence / textPath）在 MDN 上均为 Baseline: Widely available。

07

无障碍红线

这套风格的固有风险
斜排文字 旋转不改变 DOM 顺序，屏幕阅读器不受影响，但视觉阅读效率显著下降。 规则：斜排只用于 ≤3 个词的短标签，正文永远水平。
红色对比度 朱红在纸上仅 4.15:1，小字不合格。正文字号的红必须换成 --kv-red-ink（5.63:1）。
全大写 用 text-transform: uppercase 做视觉大写， HTML 里保持正常大小写 —— 否则部分读屏软件会逐字母拼读。
极端字号 vw 单位不感知容器宽度。组件放进窄栏时应改用 cqw 容器查询单位， 并始终配 overflow-wrap: anywhere 与容器 overflow: clip。
质感叠加 颗粒与网点会降低文字清晰度。质感层必须 pointer-events: none， 且不得覆盖正文区域。开启「高对比」偏好时本系统会自动关闭质感。
动效 硬切与闪动可能触发前庭不适，必须遵守 prefers-reduced-motion。
触控目标 零圆角按钮在视觉上容易做小，触控目标必须 ≥44×44px（已写入 .kv-btn 的 min-height）。
套印错位的伪元素 伪元素内容可能被读屏软件朗读造成重复。介意时改用 aria-hidden="true" 的独立 span 承载重影。
